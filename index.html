SHADE

Active

Self-Healing Adaptive Deployment Engine

An operations layer for edge AI on a Raspberry Pi 5. It watches temperature, throttle flags, memory, frame rate and camera health, steps the detector down a model ladder before the firmware throttles it, and steps back up only once it's safe. Every decision goes into an audit log you can query.

PythonYOLOv8ONNX RuntimeOpenCVSQLitePrometheussystemd

Source on GitHub

Built

  • Decision engine with hysteresis, dwell, cooldown and temperature-slope anticipation
  • Background model preload with a RAM headroom check, swapped in at a frame boundary
  • Watchdog with hang detection, restart on the emergency rung and systemd notify
  • /metrics, /status and a live status page
  • 101 automated tests, plus fault-injection runs on a simulated device

Next

  • Measure on a real Pi 5. No hardware benchmarks are claimed yet, and the thresholds are reasoned defaults.
  • Write up the simulation results as a paper.
